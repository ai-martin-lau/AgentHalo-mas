# AgentHalo 1.0.7 App Preview — 16.5 秒六语版

保留已通过的场景、真实像素角色与权限 UI，只收紧停留时间并替换语言文字。沿用确定性 `window.renderAt(t)`；没有整体倍速、插帧、配音或背景音乐。

| 段落 | 时间 | 主要动作 |
| --- | --- | --- |
| 交出长任务 | 0–2.2s | Halo 固定平和睁眼的真实 idle 0；任务条 Thinking |
| 去忙别的 | 2.2–4.6s | 工作状态，Halo 原地 running；通用代码编辑器在 0.45s 内移到前面 |
| 执行前询问 | 4.6–8.6s | 4.8s 气泡开始弹出并播放 confirm；6.6s 鼠标移动，7.3s 点击，7.8s 起收气泡，7.98s 消失 |
| 完成提醒 | 8.6–11.4s | 编辑器降到 0.6；9.0s Done + complete + jumping 一次；任务条放大至 1.04 后恢复、铃铛晃两轮；9.6s waving |
| 十只角色 | 11.4–14.4s | 按指定顺序、间隔 0.08s 出场；固定各自 idle 0，200px 可见高度，左右各 97px，标题下方垂直居中，全员到齐后统一上下轻浮 4px |
| 品牌卡 | 14.4–16.5s | 原图标、AgentHalo 和各语言收尾文字，最后 0.4s 淡出 |

局部运动保持自然速度：桌宠仍为约 120ms 一帧；权限气泡出入各 0.18s；按钮按下 0.2s；鼠标约 0.65s 平滑移动；完成提醒仍为 0.6s，jumping 五帧只播一次。字幕进出各约 0.25s，第一句直接可读；品牌卡用 0.1s 入场和 0.4s 退场以保证末句完整停留 1.6s。六句完整显示时长依次为 1.95／1.9／3.5／2.3／2.5／1.6s。

主 Halo 为真实帧整数 2 倍（约 320px 可见高度）；十角色按已通过的验收版本使用 1.25 倍最近邻绘制（200px），关闭插值。编辑器只有红黄绿圆点和十四行柔和语法色条，无产品名、图标或真实代码文字。

HUD 使用 `session-hud.html` 的真实样式和行结构，文案读取 `src/i18n.js`。权限气泡直接加载真正的 `bubble.html` / `bubble.css` / `bubble-format.js` / `bubble-renderer.js`，注入无副作用的本地演示桥接。任务标题和屏幕字幕使用 `locales/*.json`，用户提供的四组新文案逐字保留。

语言映射：en-US → en；zh-Hans → zh；zh-Hant → zh-TW；ja → ja；ko → ko；es-ES → es。全部使用同一场景与同一时间函数。

渲染仍为 1920×1080、30fps、495 帧，H.264 yuv420p / CRF 18，立体声 AAC 48kHz。全程只有无头、静音 Chrome，本目录临时 profile；不启动 App、不操作用户桌面、不播放声音、不上传。
